## 项目概要

superpowers-zh 是 **superpowers（159k+ ⭐）的完整汉化 + 4 个中国原创 Skills**，为 AI 编程工具提供**系统化的工作方法论**。支持 17 款主流 AI 编程工具（Claude Code / Copilot CLI / Hermes Agent / Cursor / Windsurf / Kiro / Gemini CLI / Codex / Aider / Trae / VS Code Copilot / DeerFlow / OpenCode / OpenClaw / Qwen Code / Antigravity / Claw Code）。

## 核心价值

1. **方法论驱动**：每个 Skill 都是一套经过实战验证的工作流程，让 AI 在写代码之前先思考（需求确认 → 方案讨论 → 再动手），避免"直接写代码但格式不对 / 缺考虑"的窘境。
2. **一键安装**：`npx superpowers-zh` 自动识别项目使用的工具并安装，无需逐条手动配置。
3. **国内生态适配**：支持 Gitee / Coding / 极狐 GitLab / CNB 等国内 Git/CI 平台，适配国内团队沟通文化。
4. **配套文档**：[《AI 编程实战 · 方法论三卷书》](https://book.aibuzhiyu.com/) 永久免费在线阅读。
