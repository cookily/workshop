## 核心思路

一套两个协同工作的 Hermes Skill：**艺术生花（Aestheflow）** 负责拆解抖音爆款视频，**灵感象限（Ideasphere）** 负责视频剪辑流水线。推荐工作流：先用艺术生花分析竞品结构 → 提炼爆款要素 → 交给灵感象限执行成品制作。

## 架构分析

```
抖音链接 ──→ 艺术生花 ──→ 分析报告 ──→ 灵感象限 ──→ 成片
              (拆解爆款)      (策略参考)      (剪辑制作)
```

### 艺术生花（Aestheflow）

- 输入抖音分享链接
- 自动：无水印下载 → 智能抽帧 → 视觉/文案/结构全维拆解
- 输出：分析报告（数据+结构+视觉+文案四维度）

### 灵感象限（Ideasphere）

- 输入本地视频素材
- 自动剪辑 → 添加字幕 → 输出成片
- 依赖 ffmpeg 做视频处理

## 关键发现

1. **完全面向**抖音自媒体生态 — 分析和生产的闭环
2. **走 Hermes tool-calling 调用** — 通过 Hermes Agent 触发分析，中间结果存 /tmp/
3. **依赖外部工具较重** — ffmpeg（抽帧/剪辑）、抖音接口（下载/数据）
4. **抖音接口不稳定** — 频率限制、链接格式限制、抽帧依赖
